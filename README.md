# Proyecto Final React - Bresso

Este es el proyecto final para el curso de React. La aplicación es una tienda en línea que permite:

- Ver productos disponibles por categoría
- Ver el detalle de cada producto
- Agregar productos al carrito
- Finalizar la compra creando una orden en Firebase

## Tecnologías utilizadas

- React
- Vite
- Firebase Firestore
- React Router
- Context API
